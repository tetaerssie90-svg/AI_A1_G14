# AI_A1_G14 Potato Cooperative Decision Pipeline

## Overview
This project implements a reproducible machine learning pipeline for the Musanze HarvestLink Cooperative.  
It covers:
- Data pipeline and vectorization
- Linear regression with gradient descent (NumPy)
- Classification (dispatch attention)
- Clustering (farm profiles)
- Prediction command interface
- UI/UX dashboard concept

The pipeline is designed to run from the command line and generate all required artifacts for assessment.

---

## Setup Instructions
### Requirements
- Python 3.10 or later
- Dependencies listed in `requirements.txt`

### Install dependencies
```bash
pip install -r requirements.txt
```
### Run the project
```bash
python run_all.py --data data/AI_A1_G14.csv --output artifacts/ --group AI-G14
```
